# 数模论文还原交付

## 核心文档

- `05_文档/数模论文_还原可编辑版.docx`：正文、公式、表格与图件的可编辑还原稿。
- `05_文档/数模论文_优化版.docx`：按竞赛表达规范优化后的版本。
- `05_文档/论文还原与优化改进说明.docx`：素材审计、数值复现、改进建议与评分诊断。
- `05_文档/数模论文_原始截图对照版.docx`：38 张源截图的逐页对照版。

对应 PDF 预览文件位于同一目录。

## 结果文件

- `result1.xlsx`：1–1800 s，每 1 s、每 0.1 cm 的温度与水分浓度。
- `result2.xlsx`：1–10800 s，每 1 s、每 0.1 cm 的温度与水分浓度。
- `result3.xlsx`：60–206940 s，每 60 s、每 0.1 cm 的水分浓度。
- `result4.xlsx`：60–183960 s，每 60 s、0–1.9 cm 每 0.1 cm及药材表面的水分浓度；超出收缩后半径的位置留空。

## 中间文件

- `00_源文件/`：主 PDF、赛题 PDF 与全部 Excel 附件的交付副本。
- `00_原始页图/`：从主 PDF 无损提取的 38 张截图、左右拆分页、哈希清单。
- `01_OCR原始/`：OCR JSON/TXT、4996 行逐框识别结果。
- `02_OCR校对/`：低置信度复核清单。
- `03_图表/`：图 1–19 的重绘 PNG。
- `04_实验复现/`：复现版 Excel 与关键结果摘要。
- `scripts/`：素材提取、OCR、有限体积/BDF 求解、绘图、文档生成和验收脚本。
- `验收/`：自动验收报告。

## 还原边界

主 PDF 是 Word 双页视图的滚动截图，不含文本层。首页标题未显示，交付稿依据摘要拟题。末帧只显示原稿附录代码至第 34 行，缺失部分无法逐字恢复，已依据正文方程和附件数据重建为可执行脚本。该限制及替代处理已写入《论文还原与优化改进说明》。
